# OB Pick Center

A Tampermonkey userscript for tracking OB Pick headcount with real-time Rodeo sync, workforce viewer, and FANS messaging.

## Install

1. Install [Tampermonkey](https://www.tampermonkey.net/) in your browser
2. Click the link below to install the script:

   **[⬇️ Install OB Pick Center](https://raw.githubusercontent.com/ttuyen099/ob-pick-center/main/ob-pick-center.user.js)**

3. Tampermonkey will open an install dialog — click **Install**

## Auto-Update

The script checks for updates automatically. When a new version is available, you'll see a banner in the panel prompting you to update. Click **Update Now** to install the latest version.

## Features

- Editable Plan HC & Actuals columns with delta tracking
- Auto-sync picker counts from Rodeo
- Expandable workforce viewer per process path
- FANS messaging (bulk & direct) with auto-retry
- Snip/screenshot to clipboard
- Light/dark mode toggle
- Draggable panel
- FC code selector
